Feature Importance

The plot shows the coefficients for each feature. Positive coefficients increase the likelihood of a particular class, while negative coefficients decrease it. Features with zero coefficients are excluded by the L1 regularization.

About L1 Regularization

L1 Regularization

  • Performs feature selection by driving some coefficients to exactly zero
  • Creates sparse models that are more interpretable
  • Can be unstable with highly correlated features

Regularization Strength (C)

  • Low C: Strong regularization, fewer features selected
  • High C: Weak regularization, more features selected
  • C = 1/λ where λ is the regularization parameter
