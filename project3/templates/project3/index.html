About This Project

This project demonstrates various explainability techniques in machine learning using the Palmer Penguins dataset. The dataset contains measurements for 344 penguins from three species observed on three islands in the Palmer Archipelago, Antarctica.

Species

Adelie, Chinstrap, Gentoo

Features

8 morphological measurements
